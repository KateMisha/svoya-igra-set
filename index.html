Правила игры

Выбираем вопросы по часовой стрелке. Счёт общий для всех раундов.

?

Обычный вопрос

  • Выбравшая команда отвечает первой. На обсуждение — 30 секунд.
  • Верно — плюс номинал. Ошибка — минус номинал. Отказ или время вышло — без штрафа.
  • После «Вопрос открыт!» отвечает первая нажавшая кнопку команда. На ответ — 5 секунд.
  • Ошибка — минус номинал и выход из розыгрыша. Повторно отвечать нельзя.
  • Первый верный ответ завершает розыгрыш. Следующий выбор — по часовой стрелке.

Кот в мешке

  • Передайте вопрос другой команде до его показа.
  • Отвечает только команда-получатель.
  • Верно — плюс номинал. Ошибка — минус номинал.
  • Перехвата кнопкой нет.
⚒

Аукцион

  • Делаем ставки до показа вопроса. Можно пропустить торги.
  • Положительная ставка — в пределах текущего счёта. Для пропуска оставьте поле пустым.
  • Самая большая ставка даёт право ответа. При равенстве — повторные торги.
  • Верно — плюс ставка. Ошибка — минус ставка.
  • Перехвата кнопкой нет.
